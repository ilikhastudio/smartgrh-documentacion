# Estados y validaciones de una ausencia

Las solicitudes pasan por un flujo de revisión. Según permisos y configuración, un responsable puede preaprobar, aprobar o rechazar una solicitud.

## Conflictos que puede detectar SmartGRH

Antes de guardar o aprobar, el sistema puede comprobar que no exista otra ausencia pendiente o aprobada para el mismo periodo, que la persona tenga cuota suficiente y que la solicitud sea compatible con registros de asistencia existentes.

## Solicitudes relacionadas

SmartGRH dispone de una acción para consultar ausencias relacionadas, útil cuando varias solicitudes afectan a fechas coincidentes o a la misma planificación.

## Rechazo

Cuando una solicitud no procede, el responsable debe utilizar el flujo de rechazo en lugar de modificar las fechas para forzar otro resultado. Esto conserva correctamente el estado de la petición.

## Exportación

Los usuarios autorizados pueden exportar el conjunto de ausencias para revisión, archivo o análisis externo.
