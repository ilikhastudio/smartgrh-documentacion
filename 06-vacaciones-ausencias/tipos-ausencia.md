# Tipos de ausencia

En **Ajustes → Vacaciones/Ausencias** pueden definirse los tipos que utilizará la empresa.

Entre las propiedades disponibles se encuentran:

| Configuración | Función |
|---|---|
| Nombre | Identifica el permiso o ausencia. |
| Mensual / anual | Define la periodicidad de la cuota. |
| Nº de días | Establece la disponibilidad del tipo. |
| Límite mensual | Restringe el consumo por mes cuando procede. |
| Remunerado / no remunerado | Clasifica el permiso. |
| Cómputo | Días laborables o días naturales. |
| Color | Identificación visual en calendarios. |
| Aplicabilidad | Determina a qué empleados puede corresponder. |
| Periodo efectivo | Puede condicionar cuándo empieza a estar disponible. |
| Periodo de prueba | Permite o impide utilizarlo durante probation. |
| Sobreutilización | Define si se permite exceder la cuota y cómo se trata. |
| Preaviso | Puede exigir anticipación. |

La pantalla de edición separa la configuración en bloques de **General, Derecho/Entitlement, Aplicabilidad y Ausencias**.

> **Configuración sensible**  
> Cambiar las reglas de un tipo afecta a solicitudes futuras y puede alterar cómo se interpreta el saldo. Documenta internamente cualquier cambio de política laboral.
