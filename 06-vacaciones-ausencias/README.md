# Vacaciones y ausencias

El módulo de **Vacaciones y ausencias** gestiona el ciclo completo de una ausencia: solicitud, validación, aprobación o rechazo, calendario y control de cuotas.

## Qué puede gestionar SmartGRH

Una solicitud puede abarcar un día, varios días o media jornada. En las medias jornadas se distingue entre primera y segunda mitad. El sistema puede relacionar la petición con el turno del empleado, los festivos aplicables, fines de semana, cuota disponible, otras solicitudes y asistencias ya registradas.

## Flujo habitual

El empleado crea la solicitud indicando tipo, fechas y motivo cuando corresponda. SmartGRH ejecuta sus validaciones y registra la petición con el estado correspondiente. Los responsables autorizados revisan después las solicitudes y pueden preaprobar, aprobar o rechazar según la configuración de la empresa.

## Calendario y cuotas

La vista de calendario ayuda a localizar ausencias en el tiempo. Las cuotas permiten saber cuánto saldo tiene disponible cada persona para los tipos que se controlan mediante días asignados.

> **Importante:** una solicitud aprobada forma parte de la planificación laboral y puede afectar a la interpretación de Asistencia. No debe eliminarse o modificarse sin revisar sus consecuencias.
