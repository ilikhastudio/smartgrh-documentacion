# Ausencias de media jornada

SmartGRH diferencia entre **primera mitad** y **segunda mitad** de la jornada. Esta distinción permite combinar correctamente asistencia y ausencia dentro del mismo día.

Para determinar la mitad del día, el sistema puede utilizar la configuración del turno del empleado o el turno predeterminado y la hora de marcado de media jornada.

La aplicación comprueba conflictos con asistencia y con otras ausencias ya pendientes o aprobadas. En determinados escenarios puede resolver la convivencia entre solicitudes de mitades opuestas del mismo día.
