# Ajustes de vacaciones y ausencias

La configuración de ausencias define las reglas que después utiliza SmartGRH al crear, validar y aprobar solicitudes.

## Tipos de ausencia

La empresa puede mantener diferentes tipos de ausencia. Cada tipo puede tener reglas propias y afectar a la cuota disponible de los empleados.

## Permisos de gestión

El sistema incluye configuración relacionada con quién puede gestionar o aprobar ausencias. Esto debe coordinarse con los roles y permisos generales de los responsables.

## Cuotas

Las cuotas se reflejan posteriormente a nivel de empleado. Antes de corregir manualmente el saldo de una persona, comprueba que el tipo de ausencia y sus reglas sean correctos.
