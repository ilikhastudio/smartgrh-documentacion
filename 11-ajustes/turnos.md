# Ajustes de turnos

Desde la configuración laboral se administran los turnos que después pueden asignarse en el cuadrante.

## Gestionar turnos

Cada turno dispone de identidad visual y reglas horarias. Consulta **Turnos y asignación → Crear y configurar un turno** para conocer los campos disponibles.

## Turno predeterminado

Un turno puede establecerse como predeterminado para facilitar la planificación habitual.

## Rotaciones

El código laboral de SmartGRH contempla gestión de **rotaciones de turnos**, incluyendo activación, empleados asociados y ejecución/automatización de rotaciones. Esta funcionalidad debe documentarse para el administrador cuando esté habilitada en su cuenta.

> Si en tu SmartGRH no aparece Rotaciones, no es necesario realizar ninguna acción: la visibilidad depende de la configuración disponible para la organización.
