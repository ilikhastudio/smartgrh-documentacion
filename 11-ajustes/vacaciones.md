# Ajustes de vacaciones y ausencias

La configuración de ausencias define las reglas con las que posteriormente trabajan las solicitudes y cuotas.

Desde esta zona se gestionan **tipos de ausencia**, reglas generales y permisos relacionados. Cada tipo puede disponer de periodicidad mensual/anual, cuota, límite mensual, condición remunerada, cómputo laboral/natural, color, periodo efectivo, reglas de periodo de prueba, sobreutilización y preaviso, además de criterios de aplicabilidad.

Consulta [Tipos de ausencia](../06-vacaciones-ausencias/tipos-ausencia.md) para una explicación funcional de cada concepto.
