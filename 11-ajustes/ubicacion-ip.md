# Ajustes de ubicación e IP

## Comprobación por radio

Activa **Comprobar radio** para exigir que el usuario esté dentro de la distancia configurada respecto a la ubicación del centro. Introduce el radio permitido en el campo correspondiente.

Para que este control tenga sentido, el navegador/dispositivo debe poder proporcionar ubicación y la ubicación del centro debe estar correctamente configurada.

## Comprobación de IP

Activa **Comprobar IP** y añade una o varias direcciones autorizadas. La pantalla permite agregar y quitar entradas de la lista.

## Elegir el control adecuado

La IP es apropiada para redes corporativas estables. La geolocalización es más útil cuando se necesita comprobar posición física. Pueden utilizarse conjuntamente si la política interna lo requiere.

> **Atención con conexiones móviles y VPN**  
> Una dirección IP puede cambiar según el proveedor, la red o una VPN. Antes de imponer una restricción estricta, comprueba cómo se conectan realmente los empleados.
