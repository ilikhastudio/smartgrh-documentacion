# Festivos

El calendario de festivos permite registrar días no laborables y determinar a qué empleados resultan aplicables.

SmartGRH dispone de vista principal, vista de tabla, alta, edición, eliminación, acciones rápidas y una herramienta para **marcar festivos** de forma específica.

Los permisos de ver, añadir, editar y eliminar festivos determinan las acciones disponibles para cada usuario.
