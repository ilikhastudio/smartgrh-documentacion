# Utilizar Mi calendario

**Mi calendario** ofrece una vista temporal de la información que corresponde al usuario.

![Mi calendario](../assets/capturas/mi-calendario.png)

## Navegación

Utiliza las flechas para avanzar o retroceder y **Hoy** para volver a la fecha actual. Puedes cambiar entre **Mes**, **Semana**, **Día** y **Agenda**.

## Filtro por tipo

El selector **Tipo** permite limitar los elementos mostrados. SmartGRH construye el calendario en función de módulos y permisos, por lo que dos usuarios pueden ver información diferente.

## Uso laboral

Dentro del alcance laboral, el calendario sirve como referencia para planificación, ausencias y otros elementos disponibles para la cuenta. Debe utilizarse como vista de consulta; las modificaciones se realizan normalmente desde el módulo de origen correspondiente.
