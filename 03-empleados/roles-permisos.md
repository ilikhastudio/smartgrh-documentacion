# Roles y permisos de empleados

SmartGRH separa el **rol** del usuario de los **permisos concretos**. El rol sirve como perfil general, mientras que los permisos determinan qué puede consultar o modificar realmente.

## Acciones habituales protegidas por permisos

Entre otras, existen capacidades diferenciadas para ver empleados, añadirlos, editarlos, eliminarlos, cambiar roles, consultar asistencia, gestionar turnos, ver ausencias y aprobar o rechazar solicitudes.

## Por qué dos usuarios ven pantallas distintas

La aplicación adapta menús, botones y acciones al contexto del usuario. Por eso un administrador puede ver **Agregar Empleado**, acciones masivas o edición de asistencia mientras que un empleado sólo dispone de las opciones necesarias para su jornada.

## Cambio de rol

El listado de empleados puede mostrar un selector de rol para usuarios autorizados. Antes de modificarlo, comprueba el alcance del nuevo perfil, especialmente si concede permisos de administración.

> **Principio recomendado:** asigna únicamente los permisos necesarios para la función de cada persona.
