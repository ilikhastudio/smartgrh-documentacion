# Fichajes y control horario

El módulo de **Asistencia/Fichajes** permite consultar y gestionar el registro de jornada de los empleados.

SmartGRH puede trabajar con entradas y salidas, turnos asignados, días festivos, ausencias aprobadas, medias jornadas, ubicación del fichaje y modalidad de trabajo. La información disponible depende de la configuración de la empresa y de los permisos del usuario.

## Funciones principales

Desde este módulo se puede, según permisos:

- consultar la asistencia mensual;
- revisar entradas, salidas y horas registradas;
- consultar la asistencia de un empleado;
- analizar registros por horas;
- consultar fichajes con ubicación registrada;
- añadir o corregir registros de asistencia;
- marcar registros de forma masiva;
- importar registros desde Excel;
- exportar registros de asistencia;
- generar el registro de jornada para control legal.
