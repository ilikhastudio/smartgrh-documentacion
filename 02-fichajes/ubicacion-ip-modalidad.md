# Ubicación, IP y modalidad de trabajo

SmartGRH puede guardar información adicional para reforzar la trazabilidad del fichaje. Estas funciones dependen de **Configuración de asistencia**.

## Ubicación

Si está habilitado **Guardar ubicación actual**, el registro puede conservar coordenadas de entrada y salida. Cuando además se activa la comprobación por radio, el sistema compara la localización del usuario con la ubicación configurada para la empresa y el radio permitido.

La vista de mapa solo puede representar fichajes que contienen coordenadas válidas.

## Restricción por IP

La empresa puede activar la comprobación de IP y mantener una lista de direcciones autorizadas. Esta opción se utiliza cuando el fichaje debe realizarse desde redes concretas.

## Trabajando desde

El fichaje puede identificar la modalidad como **Oficina**, **Casa** u **Otro**. Si se utiliza “Otro”, el registro puede guardar una descripción adicional del lugar.

> **Ubicación e IP son controles diferentes**  
> La geolocalización valida la posición del dispositivo; la IP identifica la red desde la que se realiza la conexión. La empresa puede utilizar una, ambas o ninguna.
