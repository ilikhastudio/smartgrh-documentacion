# Configurar el fichaje desde una ubicación autorizada

SmartGRH puede utilizar **geolocalización**, **radio de distancia** y/o **direcciones IP autorizadas** para reforzar las reglas de fichaje. Estas opciones se administran desde **Ajustes → Configuración de asistencia**.

## Geolocalización y radio

Activa la comprobación por radio cuando quieras validar que el dispositivo se encuentra dentro de una distancia permitida. Define correctamente la ubicación de referencia y el radio admitido.

Cuando esta función está activa, el navegador o dispositivo necesita proporcionar una ubicación válida. Si el usuario deniega el permiso de ubicación, el fichaje puede no disponer de la información necesaria para superar la validación.

## Restricción por IP

Puedes configurar direcciones IP autorizadas para permitir el fichaje desde redes concretas. Es especialmente útil en instalaciones con conexión corporativa estable.

> **Atención:** si la conexión utiliza una IP pública dinámica, esta puede cambiar. Una lista de IP desactualizada puede impedir fichar a usuarios que sí están físicamente en el centro de trabajo.

## Comprobación recomendada

Después de cambiar estas opciones, realiza una prueba con una cuenta de empleado desde una ubicación y red reales antes de considerar terminada la configuración.
