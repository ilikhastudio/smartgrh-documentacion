# Un empleado olvidó fichar

Cuando una persona ha trabajado pero no existe un registro correcto de entrada o salida, la incidencia debe resolverse desde **Administración → Asistencia** por un usuario con permiso para gestionar fichajes.

## Antes de modificar nada

Comprueba primero el **empleado**, la **fecha**, el **turno asignado** y si ese día existe una ausencia, festivo o día libre. La matriz de asistencia puede mostrar un día como ausente aunque la causa real sea una configuración de turno o calendario.

## Crear o completar el registro

1. Entra en **Asistencia** y selecciona el mes y año correspondientes.
2. Localiza al empleado y el día afectado.
3. Utiliza la acción de **Marcar asistencia** o abre el registro existente, según el caso.
4. Selecciona el turno correcto.
5. Introduce la hora de entrada y, si procede, la hora de salida.
6. Revisa si corresponde marcar retraso, media jornada, modalidad de trabajo o añadir una observación.
7. Guarda el registro.

SmartGRH realiza validaciones para evitar inconsistencias, como determinados solapamientos o conflictos con ausencias registradas.

> **Recomendación:** utiliza el campo de observaciones cuando la corrección sea manual y convenga dejar constancia del motivo.

## Comprobación final

Vuelve a la vista **Resumen** o **Empleado** y confirma que el día aparece con el estado esperado y que las horas registradas son correctas.
