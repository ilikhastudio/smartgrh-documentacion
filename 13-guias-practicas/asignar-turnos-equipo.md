# Asignar turnos a varios empleados

Para planificar un equipo completo utiliza **Administración → Asignación de turnos**. Esta pantalla está pensada para trabajar con el cuadrante mensual y permite aplicar asignaciones masivas.

![Asignación de turnos](../assets/capturas/asignacion-turnos.png)

## Asignación masiva

1. Abre **Asignación de turnos**.
2. Selecciona el año y el mes que vas a planificar.
3. Pulsa **Asignar turnos masivos**.
4. Selecciona los empleados afectados.
5. Selecciona el turno que quieres aplicar.
6. Define las fechas o el periodo correspondiente.
7. Revisa el resumen antes de confirmar.
8. Guarda la asignación.

Después, vuelve al **Resumen** mensual y verifica visualmente que cada empleado tiene el código/color de turno esperado en los días correctos.

## Si te has equivocado

Utiliza **Borrar turnos masivamente** para retirar asignaciones de un conjunto de empleados o fechas. Hazlo con cuidado: borrar una planificación puede afectar a la interpretación posterior de asistencia y jornada.

> **Consejo:** configura primero los turnos en **Gestionar turnos** y realiza después la planificación mensual. Evita crear variantes de turno innecesarias solo para resolver un día puntual.
