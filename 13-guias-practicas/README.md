# Guías prácticas

Esta sección resuelve situaciones habituales sin obligarte a conocer primero toda la estructura de SmartGRH. Cada guía indica **dónde entrar, qué revisar, qué acción realizar y qué comprobar al terminar**.

Las opciones visibles pueden variar según el rol y los permisos de cada usuario. Si un botón descrito no aparece, consulta con la persona administradora de SmartGRH.
