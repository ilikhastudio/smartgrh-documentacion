# Resolver una solicitud de teletrabajo

Si las solicitudes de teletrabajo están habilitadas en **Configuración de asistencia**, los empleados pueden solicitar trabajo remoto para una fecha concreta o un intervalo.

## Qué revisar

Antes de aprobar, comprueba las fechas, el motivo cuando se haya indicado y posibles conflictos. SmartGRH valida, entre otros casos, solicitudes solapadas y ausencias aprobadas que coincidan con el periodo solicitado.

## Estados

Una solicitud nueva queda **pendiente**. Desde ese estado puede ser **aprobada** o **rechazada** por quien tenga autorización. El empleado puede cancelar una solicitud mientras siga pendiente. Al rechazar, el sistema puede exigir un motivo de rechazo.

> **Importante:** si el módulo desaparece para los usuarios, revisa primero que **Habilitar solicitudes de teletrabajo** continúe activo en Ajustes.
