# Reglas y conflictos de teletrabajo

SmartGRH aplica reglas concretas antes de crear una solicitud:

- No se pueden solicitar fechas pasadas.
- Un intervalo no puede superar **31 días**.
- La fecha final no puede ser anterior a la inicial.
- No puede existir otra solicitud pendiente o aprobada que se solape con esas fechas.
- No puede existir una ausencia aprobada dentro del intervalo solicitado.
- El motivo puede tener hasta 1.000 caracteres.

Estas validaciones evitan que un mismo día figure simultáneamente como teletrabajo y como ausencia aprobada.
