# Teletrabajo

El módulo de **Teletrabajo** permite solicitar y gestionar días de trabajo remoto cuando la empresa ha habilitado esta función en Configuración de asistencia.

Una petición puede corresponder a una fecha única o a un rango. SmartGRH impide solicitar fechas pasadas y comprueba incompatibilidades con otras solicitudes de teletrabajo y con ausencias aprobadas.

Las solicitudes siguen estados diferenciados: **Pendiente, Aprobada, Rechazada y Cancelada**. Sólo las peticiones que se encuentren en un estado válido pueden ejecutar cada transición.

> Si el módulo no aparece en tu cuenta, revisa **Ajustes → Configuración de asistencia → Habilitar solicitudes de teletrabajo** y los permisos del usuario.
