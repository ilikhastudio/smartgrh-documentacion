# Cómo leer la pantalla de Asignación de turnos

La pantalla de **Asignación de turnos** está pensada para responder rápidamente a una pregunta: **¿qué horario tiene cada persona cada día?**

![Asignación de turnos](../assets/capturas/asignacion-turnos.png)

## Filtros

**Empleado** limita el cuadrante a una persona concreta. **Departamento** permite revisar únicamente un equipo. Son especialmente útiles cuando la plantilla es grande.

## Acciones superiores

**Asignar turnos masivos** abre la planificación por lotes. **Borrar turnos masivamente** elimina asignaciones de un periodo seleccionado. **Exportar** genera una salida del cuadrante y **Gestionar turnos** abre el catálogo de horarios disponibles.

> **Permisos:** las acciones de edición pueden no aparecer a un empleado sin permisos de gestión de turnos.

## Resumen y solicitudes

La pestaña **Resumen** contiene el cuadrante. **Solicitudes de cambio de turno** muestra las peticiones de modificación que deben tramitarse separadamente.

## Año, mes y matriz

Selecciona el año y después el mes. Cada celda cruza un empleado con una fecha. El código/color del turno permite identificar rápidamente el horario asignado.

Una celda vacía no debe interpretarse automáticamente como ausencia: puede significar que no existe una asignación específica para esa fecha. La interpretación final depende de la configuración y del turno predeterminado de la empresa.

## Antes de modificar una celda

Comprueba la fecha, el empleado y el horario que quieres aplicar. Si la jornada ya ocurrió y existen fichajes, revisa después **Asistencia** para confirmar que el registro real sigue siendo coherente.
