# Turnos y planificación

El módulo de turnos permite consultar y organizar el **cuadrante de trabajo** de los empleados. SmartGRH distingue entre la definición de los tipos de turno y la planificación concreta asignada a cada persona y fecha.

Las posibilidades de gestión dependen principalmente de los permisos **ver cuadrante** y **gestionar turnos de empleados**.
