# Organización laboral

**Organización** representa cómo se estructura la plantilla en SmartGRH. En la interfaz actual agrupa **Designación, Departamento y Reconocimiento**.

Los departamentos y designaciones no son simples etiquetas: aparecen en Empleados, filtros de Asistencia, asignación de turnos y reglas de aplicación de determinadas funciones laborales.

![Designaciones](../assets/capturas/designacion.png)

## Designaciones

Representan el **cargo, puesto o función** de una persona. SmartGRH permite crear relaciones padre-hijo para construir una jerarquía de puestos.

## Departamentos

Representan **áreas, equipos o unidades organizativas**. También pueden tener un departamento padre y formar una estructura jerárquica.

![Departamentos](../assets/capturas/departamentos.png)

## Reconocimiento

Permite registrar agradecimientos o premios vinculados a empleados y consultar el histórico autorizado.
