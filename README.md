# Manual de usuario de SmartGRH

Bienvenido al manual de usuario de **SmartGRH**.

Este manual explica de forma práctica cómo utilizar las funciones del sistema. Está orientado al usuario final: empleados, responsables y administradores. Las opciones visibles pueden variar según los permisos asignados por la empresa.

## Cómo utilizar este manual

Cada apartado explica:

- qué permite hacer una función;
- dónde encontrarla;
- qué información muestra;
- cómo realizar las acciones habituales;
- qué permisos pueden afectar a su disponibilidad;
- avisos y situaciones especiales que conviene conocer.

> **Importante:** si una opción descrita no aparece en su cuenta, normalmente significa que el módulo no está habilitado o que su perfil no dispone del permiso correspondiente.
