# SmartGRH · Centro de Ayuda

SmartGRH reúne en un único entorno la gestión laboral diaria de la empresa: **empleados, fichajes, control horario, turnos, vacaciones y ausencias, teletrabajo, festivos, organización y calendario**.

Este manual está pensado tanto para empleados como para responsables de equipo y administradores. Las funciones que ve cada persona dependen de su rol y de los permisos configurados.

## Cómo leer este manual

Las páginas describen la interfaz real de SmartGRH y separan claramente las operaciones del día a día de las opciones de configuración. Cuando una función requiere privilegios concretos se indica como una cuestión de **permisos**; si no ves una opción que aparece en el manual, normalmente se debe al rol de tu usuario o a que la función está desactivada en Ajustes.

> **Ámbito de este centro de ayuda:** documentación laboral y de recursos humanos de SmartGRH. No se incluyen módulos genéricos heredados de la plataforma base que no forman parte del producto laboral.
