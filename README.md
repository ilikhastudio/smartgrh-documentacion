# Manual de usuario de SmartGRH

**Centro de Ayuda oficial para usuarios, responsables y administradores de SmartGRH.**

SmartGRH centraliza el **control horario**, la **gestión de empleados**, **asistencia**, **turnos**, **festivos**, **ausencias**, **teletrabajo**, **organización**, **reconocimientos**, **calendario** y la configuración relacionada con la jornada laboral.

Este manual está diseñado para explicar no sólo dónde se encuentra cada opción, sino **qué hace, cuándo utilizarla y qué efecto tiene sobre el resto del sistema**.

## Cómo utilizar este manual

Empieza por **Panel de inicio** si eres usuario de la aplicación. Los responsables de equipo encontrarán especialmente útiles **Asistencia**, **Turnos**, **Festivos** y **Organización**. Los administradores deben revisar también **Empleados**, **Permisos** y **Ajustes**.

> La interfaz se adapta al plan, módulos y permisos de cada cuenta. Por ello algunas funciones descritas pueden no aparecer para todos los usuarios.
