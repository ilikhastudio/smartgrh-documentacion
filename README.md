# Manual de usuario de SmartGRH

**Centro de Ayuda de SmartGRH para empleados, responsables y administradores.**

SmartGRH reúne en un único entorno la operativa laboral diaria de la empresa: **fichaje y control horario, asistencia, empleados, organización, turnos, vacaciones y ausencias, teletrabajo, festivos, calendario y reconocimientos**.

Este manual está orientado a tareas reales. Cada apartado explica **qué hace una pantalla, qué significan sus opciones, cómo ejecutar las acciones habituales, qué permisos pueden intervenir y qué otras partes del sistema pueden verse afectadas**.

## Por dónde empezar

Si utilizas SmartGRH como empleado, comienza por **Panel de inicio**, **Fichajes**, **Vacaciones y ausencias**, **Teletrabajo** y **Mi calendario**. Si coordinas personas o administras la cuenta, revisa además **Empleados**, **Organización**, **Turnos**, **Festivos** y **Ajustes**.

## Alcance de este Centro de Ayuda

La aplicación parte de una base tecnológica que contiene módulos adicionales, pero este manual documenta exclusivamente la **parte laboral y de Recursos Humanos utilizada por SmartGRH**. No se incluyen módulos genéricos que no formen parte de la experiencia laboral activa.

> **Nota sobre permisos:** SmartGRH adapta menús, botones y datos al rol y permisos de cada usuario. Es normal que algunas acciones descritas sólo aparezcan a responsables o administradores.
